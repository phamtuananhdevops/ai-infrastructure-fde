# Learning Context — AI Infrastructure FDE

This file is the durable, portable context for any AI mentor, including a different ChatGPT account.

## Goal
Transition from System Engineer / enterprise Application Operations into AI Infrastructure / Forward Deployed Infrastructure Engineering through a 36-week, project-based portfolio.

## Constraints
- Study time: 8–10 hours per week.
- Intended lab environment: WSL2 Ubuntu with sudo.
- No personal NVIDIA GPU. Use CPU inference first and rent GPU briefly when necessary.
- Minimize cloud costs; use local and open-source tools first.
- Language: conversational Vietnamese for coaching; practice English for technical documentation and customer communication.

- Learner has access to Udemy Business; use targeted hands-on courses, not certification study. Course availability in their organizational catalog is not yet verified.

- English listening is adequate but speaking is weak; prioritize spoken role-play and explanation. English confidence is limited: teach technical topics in Vietnamese first, then practice simple professional English; see [Technical English](TECHNICAL_ENGLISH.md).

## Method
**Build → Break → Fix → Explain.** One evolving Enterprise AI Inference Platform project.

AI mentor expectations:
1. Act as a Senior AI Infrastructure / Forward Deployed Engineer.
2. Assign one task at a time with acceptance criteria and evidence rubric.
3. Do not disclose troubleshooting answers or root causes before the learner investigates.
4. Grade using real commands, logs, configuration and test results, not assertions.
5. Document decisions, failures, remediation, cleanup and costs.
6. Keep project status and handoff files accurate. Do not mark work completed without evidence.
7. Never commit credentials, real customer data or production configurations.
